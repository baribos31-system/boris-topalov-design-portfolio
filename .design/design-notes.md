# Дизайн-система портфолио

## Архетип поверхности

**Главная — Decide / Learn.** Посетитель решает, стоит ли работать с дизайнером: один тезис в hero, затем доказательства (кейсы), затем контакт. Hero здесь уместен, но это не центр-стек: заголовок, лид и действия выровнены по левому краю, кейсы идут сеткой 3 → 2 → 1.

**Страница кейса — Decide / Learn, вторичный Explore.** Основной сценарий — убедить читателя через задачу / процесс / результат; галерея внутри блока результата работает как Explore (просмотр материала), поэтому это сетка изображений с подписями, а не декоративные карточки.

Следствие для композиции: никаких иконочных фич-плиток, центрированных секций и «трёх преимуществ». Ритм задают типографика, волосяные линии и асимметрия текстовых блоков.

## Типографика

Осознанная пара, без веб-шрифтов и внешних зависимостей (сайт открывается через `file://`, шрифты должны работать офлайн):

- **Display:** `--font-display` — гуманистический old-style serif: Iowan Old Style → Palatino Linotype → Book Antiqua → Palatino → Georgia. Даёт редакционный, «печатный» голос и отличает портфолио от SaaS-шаблона. Вес 500: в Palatino/Georgia ложится в regular — намеренно лёгкий, иерархию держит крупный кегль.
- **Text / UI:** `--font-sans` — Segoe UI → Helvetica Neue → Helvetica → Arial. Нейтральный гротеск для тела, навигации, кнопок и мелких подписей; хорошее покрытие Windows/macOS без загрузки файлов.

Inter и `system-ui` по умолчанию не используются: это первый признак шаблонного AI-дизайна, а пара serif + гротеск осмысленно разделяет «голос» и «интерфейс».

| Token | Значение | Роль | Line-height | Tracking |
|---|---|---|---|---|
| `--fs-hero` | clamp(40px, 7vw, 84px) | h1 главной и кейса | 1.05 | -.02em |
| `--fs-h2` | clamp(28px, 3.4vw, 44px) | заголовки секций | 1.08 | -.015em |
| `--fs-h3` | 22px | карточки, шаги | 1.25 | -.01em |
| `--fs-body` | 17px | основной текст | 1.6 | 0 |
| `--fs-small` | 14px | подписи, мета, eyebrow | 1.5 | +.14em только eyebrow (uppercase) |

Правила: заголовки `text-wrap: balance`, абзацы максимум 68ch, лид 56–60ch; h1 ограничен по ширине в `em` — 11.5em на главной и 13em в кейсе, чтобы длинный русский заголовок держал 3–4 строки, а не пять. Крупные заголовки не ломаются на одиночные слова за счёт `overflow-wrap: break-word`.

## Палитра

Нейтральная серая шкала + один зелёный. Зелёный выбран как спокойный «природный» маркер (маршрут, рост, движение), а не дефолтный индиго; он присутствует в малой дозе — линии, точки, заливки кнопок, один акцент на обложках.

| Token | Hex | Роль | Контраст на белом |
|---|---|---|---|
| `--text` | #0E0E10 | основной текст | 19.3:1 |
| `--muted` | #6B7280 | вторичный текст, подписи | 4.8:1 (4.5:1 на `--surface`) |
| `--accent` | #16A34A | графика, маркеры, линии — только non-text | 3.3:1 (проходит 3:1 для UI) |
| `--accent-strong` | #0F7D3B | заливка primary-кнопки | 5.2:1 с белым текстом |
| `--accent-hover` | #0B5A2A | hover/pressed зелёной кнопки | 8.4:1 с белым текстом |
| `--accent-ink` | #0F6B33 | мелкий зелёный текст (номера шагов, ссылки) | 6.6:1 |
| `--accent-soft` | #E8F5EC | подложки, selection | — |

Правило: яркий `--accent` никогда не несёт мелкий белый текст (3.3:1 недостаточно). Белый текст допускается только на `--accent-strong` / `--accent-hover`.

## Сетка и отступы

- Контейнер `.wrap`: max-width 1120px, gutter 24px (20px ≤640px).
- Шкала: 8 / 16 / 24 / 40 / 64 / 96px (`--space-1…6`).
- Секция: 96px по вертикали (64px ≤640px); соседняя секция сверху 64px, чтобы суммарный ритм был ~160px, а не 192px.
- `.case-grid`: 3 колонки → 2 на 900px → 1 на 640px; `.gallery`: 2 → 1 на 640px. Везде `minmax(0, 1fr)` — без горизонтального скролла (проверено на 1440 / 900 / 640 / 360: `scrollWidth == clientWidth`).
- Брейкпоинты: 900 / 640 / 420px; мобильная проверка от 360px.
- Внутренние отступы карточек 24px, CTA clamp(32px, 5vw, 56px).

## Компоненты

**Header.** Sticky, белый, нижняя линия 1px; inner 72px. Логотип — serif-надпись + ромб 9px акцентного цвета, поворот на hover. Навигация 15px muted → text, подчёркивание через `scaleX` 0→1. `.lang-toggle` — кнопка-пилюля 44px на `--surface`, uppercase 12px, hover — белый фон и `--line-strong`. ≤640px шапка в две строки: логотип + переключатель, навигация ниже; высота ~96px.

**Buttons.** Высота ≥44px, pill, 600. Primary: `--accent-strong` → `--accent-hover`, подъём 1px, зелёная тень. Ghost: прозрачный, граница `--line-strong` → `--text`, фон `--surface`. Focus-visible: контур 2px `--accent`, offset 3px (у ghost — цвет текста). Нажатие возвращает в 0.

**Card.** Белая, граница 1px, radius 16, padding 24.

**Case-card.** Обложка 16:9, `object-fit: cover`, без внутреннего radius (скругляет карточка через overflow). Заголовок с отступом 24px сверху, подпись 8/24. Hover: `translateY(-2px)`, граница `--line-strong`, `--shadow-lift`; focus-visible — зелёный контур.

**Hero.** Сетка 88px, растворённая радиальной маской вправо-вверх; h1 max 11.5em; лид 56ch; кнопки flex-wrap, ≤420px — в столбец на всю ширину.

**Case-hero.** h1 `--fs-hero` max 13em; лид max 760px; eyebrow с акцентной чертой 18px.

**case-meta.** Flex-wrap по baseline; между элементами точка `·` через `::before` на `--muted` (55%); значения `strong` — цвет текста. Поддерживаются `dl/dt/dd`.

**case-block.** 64px по вертикали, между блоками волосяная линия. h2 max 24ch, отступ 24px до текста; внутри работает обычная типографика списков и ссылок с подчёркиванием.

**gallery.** 2 колонки, gap 24, изображения с границей 1px и radius 16; `figcaption` 14px muted. Модификатор `.gallery__item--wide` на всю ширину.

**steps.** Список-счётчик `01, 02…` цветом `--accent-ink`, колонка номера 44px, строки разделены 1px линией, описание muted max 62ch.

**tags.** Пилюли 13px на `--surface` с границей; `white-space: nowrap`.

**case-cta.** Полноширинная полоса на `--surface` с верхней границей 1px; контент внутри `.wrap` (max 1120px), padding-block 96px (64px ≤640px). Заголовок → текст 24px, кнопки через `.hero__actions` с отступом 24px, ссылка «Все кейсы» с подчёркиванием.

**Footer.** Верхняя граница, 40px по вертикали, flex space-between; ссылки с подчёркиванием, hover — `--accent-ink`.

## Состояния и доступность

- Все интерактивные элементы имеют реальные `:hover` и `:focus-visible` (контур 2px, offset 3px); hover не единственный сигнал.
- Тач-цели: кнопки ≥44px, навигация с padding; на ≤420px кнопки hero растягиваются на всю ширину.
- `prefers-reduced-motion`: отключаются transitions, hover-подъёмы и smooth scroll.
- Контраст ключевого текста: основной 19.3:1, muted 4.8:1, мелкий зелёный 6.6:1, белый на кнопке 5.2:1.
- Изображения: `max-width: 100%`, `height: auto`; alt задаёт HTML-автор.
- Горизонтальный скролл отсутствует на 360–1440px (проверено в браузере).

## Обложки

`youtravel/cover.svg` и `case-3/cover.svg` — 1600×900, светлый фон, сетка 80px, тонкие окружности, малая доза зелёного, без текста и растровых вставок. Общий мотив (сетка + зелёный угловой штрих) связывает кейсы, композиции разные: маршрут с мини-карточкой vs. панель интерфейса с палитрой. Это абстрактная графика, а не имитация продуктовых скриншотов: нет выдуманных цифр и фейковых данных.

**Что правил.** Только тот регистр, который назвал аудит: диагноз — типографика (признак 9), поэтому выполнена перетипографика (serif-заголовки, другой текстовый гротеск, пересчёт трекинга и интерлиньяжа), а не смена композиции. Дополнительно усилен контраст primary-кнопки: белый текст переведён с `--accent` (3.3:1) на `--accent-strong` (5.2:1).

**После правок — 0/10.** Ни один из десяти признаков не срабатывает: композиция соответствует Decide/Learn, декор сведён к сетке и двум обязательным обложкам, типографика выбрана под задачу, акцент один и осмысленный.
